# 物件ハザードチェック

賃貸物件の住所を入れるだけで、ハザードマップの確認を項目ごとにまとめて行うWebアプリです。
対象は洪水・内水・土砂災害・高潮・津波・地形と標高・避難場所です。

- **国のデータ**：国土交通省「重ねるハザードマップ」と国土地理院のオープンデータで自動判定します。
- **自治体のPDF**：市区町村のハザードマップPDFを登録すると、凡例の色で判定し、地点周辺の切り抜きを表示します。
- 部屋の階数を考慮します。浸水深が部屋の床より低い場合は危険度を下げます。
- 判定履歴の保存と、登録データのバックアップができます。
- データはすべて端末内（IndexedDB）に保存し、サーバーには送りません。

## 公開（GitHub Pages）

Settings → Pages → Source を「Deploy from a branch」にし、Branch を `master`、フォルダを `/ (root)` にします。

## 構成

- `index.html`, `css/`, `js/`：アプリ本体（ビルド不要の静的サイト）
- `vendor/`：Leaflet 1.9.4、pdf.js 3.11.174（各 LICENSE 同梱）
- `sw.js`, `manifest.webmanifest`：ホーム画面追加（PWA）用

判定は目安です。契約前には必ず自治体の最新ハザードマップで確認してください。
